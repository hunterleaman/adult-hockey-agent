# Pipeline Phase Gating: `/grill-me` is the Mandatory Entry Point (HARD RULE)

The Development Pipeline (table in `CLAUDE.md`) is enforced deterministically by `lib/workstream.sh` and the per-workstream state file at `.workstream/{slug}.md` (markdown body = grill transcript, YAML frontmatter = phase ledger). Phases 1-3 are **GATED**: the corresponding slash commands refuse to advance without prior-phase artifact evidence on disk. Phases 4-7 are **TRACKED-only**: pointers to GitHub issues are stored immutably in the file but completion state is NOT recorded in the ledger; the operator queries GitHub directly when they need it, so by-construction the ledger cannot drift from GitHub on those phases. The ledger is **operator-trust evidence** (R5): the gate eliminates accidental phase-skips, not a malicious operator who edits frontmatter to forge timestamps.

- **Workstream identity.** Slug is `^[a-z0-9-]+$`, length 1..64, no leading or trailing `-`. One state file per slug at `.workstream/<slug>.md`. `/grill-me` writes the file atomically via `set -C` (O_EXCL); collision = hard refuse.
- **GATED phases (1-3).**
  - Phase 1 / `/grill-me`: atomic-creates `.workstream/<slug>.md` and seeds `phases.grill.started_at`. Phase-1 evidence = file exists + `phases.grill.started_at` set (loose definition; gate does not assess grill quality).
  - Phase 2 / `/write-a-prd`: refuses without Phase-1 evidence; on success advances `phases.prd.{started_at, completed_at, artifact}` with `artifact: "issue:<N>"`.
  - Phase 3 / `/prd-to-issues`: refuses without Phase-2 evidence; on success advances `phases.issues.{started_at, completed_at, artifacts: [...]}` as a YAML sequence.
- **TRACKED-only phases (4-7).** Implementation, AI review, human review, close. The state file stores `implementation_pointer.{parent, children}` as immutable issue refs. Completion state is NOT recorded in the ledger at all: drift between ledger and GitHub is impossible by construction because nothing is stored to drift. The operator queries GitHub directly (`gh issue view <N>` / `gh pr list --search "is:closed linked:<N>"`) when they need completion status; v1 does not ship a live-read helper (see ADR Q3: that helper is future intent, not shipped behavior).
- **Slug resolution cascade** (every gated command + `/wind-up`):
  1. `--slug=<foo>` flag (always wins).
  2. Branch regex `^[0-9]+-(.+)$` (strict; non-match falls through).
  3. R6 bootstrap-empty exemption: zero regular files in `.workstream/` (the `.gitkeep` placeholder and the `_overrides.log` audit log are excluded from the count; any other file, `.md` or otherwise, counts) exits 2 (gate N/A; fresh consumer repos are not blocked).
  4. Exactly-one-open `.workstream/*.md` (open = `closed_at` absent OR `closed_at: null` per R3 strict-leading frontmatter parse).
  5. Interactive disambiguate (TTY only; non-TTY refuses explicitly).
  6. Refuse with explicit error.
- **Mutation safety.** Atomic create via `set -C` (O_EXCL); subsequent ledger advances guarded by per-slug `flock` at `${TMPDIR:-/tmp}/cpt-workstream-<slug>.lock` when available, naked-fallback + warn otherwise (R2; mirrors `lib/dispatch.sh`). Frontmatter rewrites are tmp-file + atomic `mv` on the same filesystem.
- **`/orient`** when the slug cascade resolves AND a recent `prompt_*.md` is identified, validates that prompt's DO-FIRST against the ledger and warns inline on phase-skip; independently surfaces a non-conformant-file count whenever any `.workstream/*.md` fails the R3 frontmatter contract. Both are advisory (`/orient` warns, never refuses); resolver/parse failures fall through silently rather than blocking the report.
- **`/wind-down`** auto-corrects a phase-skipping DO-FIRST in the resume prompt (e.g. rewrites `/write-a-prd` to `/grill-me` when no Phase-1 evidence exists) and appends a `> note: auto-corrected because <reason>` marker. Idempotent: re-running on a clean prompt is a byte-for-byte no-op.
- **`/wind-up`** runs the cascade and surfaces a `workstream: slug 'X' resolved via Y` line on stderr (flag / branch / single-open / interactive / foundation cascade) so the operator can spot a wrong pick before acting. When the cascade refuses (no slug, ambiguous in non-TTY, no open files), `/wind-up` falls back to the most-recent `prompt_*.md` in the memory directory and flags the fallback explicitly in its output (the foundation resolver itself refuses on non-TTY ambiguity; the slash-command wrapper layers the recency-fallback so a stale wind-up still resumes something rather than aborting).
- **CI gate.** `bash lib/workstream.sh ci-validate <pr#>` runs PR-only in `.github/workflows/verify-all.yml` and performs three checks: PR-Workstream-Link (PR title/body/branch references a slug whose `.workstream/<slug>.md` is conformant), Phase-1-Evidence (`phases.grill.started_at` set), and Override-Audit-Sane (no in-place edits / deletions / renames / binaries on `.workstream/_overrides.log`). Failures = red-X check (NOT auto-merge-block at v1).
- **Bootstrap-empty exemption (R6).** When `.workstream/` contains zero regular files (excluding `.gitkeep` and `_overrides.log`; any other file, `.md` or otherwise, counts), the gate is N/A and `ci-validate` exits 0 with a `gate\tNA` status. A fresh repo's first `/grill-me` activates the gate.
- **Override / escape hatch.** Pass `--skip-phase-gate REASON="<rationale>"` to any GATED command. Empty / missing REASON refuses. On valid override, a single TSV line is appended atomically to `.workstream/_overrides.log` (`<ISO-8601 UTC>\t<command>\t<slug>\t<sanitized reason>`) BEFORE the command proceeds. R4-sanitized: control chars / ANSI escapes / embedded newlines/tabs are stripped (NOT replaced); reason capped at 1000 bytes (`WORKSTREAM_OVERRIDE_REASON_MAX`). Canonical reason for legacy in-flight branches: `RETROFIT-LEGACY-BRANCH: <branch> predates gate`. The audit log is committed and append-only: `Override-Audit-Sane` enforces in CI.
- **Output sanitization (R4).** Three modes in `_workstream_sanitize`: `pr` (`printf '%s\n'`: never `echo -e`, never bare `printf "$msg"`), `log` (strip control chars via `tr -d '[:cntrl:]'`), `warn` (strip ANSI CSI sequences). Applied at every external sink: PR-text interpolation in CI, `_overrides.log` appends, CLI warnings.
- **Scope (v1-accepted limitations).** Forgeable evidence (operator-trust only, no signed evidence / commit-SHA anchoring); fork PRs (workstream file may not exist on base: maintainer review is the mitigation); branch-protection-admin / web-UI / GraphQL `gh pr merge` bypass (gate is red-X, not hard-block); two-session race on no-flock hosts (small window after `set -C` creation). All accepted; solo-operator project.

**Why it matters:** Layered failure observed in a recent session: `/wind-down` wrote a Phase-2 DO-FIRST without checking phase state, `/orient` relayed it verbatim, `/write-a-prd` ran cold, the pipeline table is descriptive not enforced, and zero deterministic gates existed. For a flagship reference deployment that must dogfood its own kit flawlessly, "documented but unenforced" was a defect. This rule plus `lib/workstream.sh` make the pipeline exactly as reliable as the file system, not as the next session's prompt fidelity.
